# 영천 게임 스토리 작성 키트 — 먼저 읽기

## 1. 이 게임은 이렇게 돌아가요 (3분 요약)

- 칠월칠석을 앞둔 **2박 3일** 영천 여행. 주인공은 와인 체험하러 온 청년.
- 매일 **09:00 시작 → 22:00까지 숙소**(취하리 청년마을 · 시청 · 한의마을 · 은해사) 도착. 못 가면 게임오버.
- 플레이어는 **지도에서 장소를 골라 이동**합니다. 이동은 30분(시청↔시장은 0분), 체험은 각자 정한 시간만큼 걸려요.
- 장소에 도착하면 **그 장소의 도착 장면**이 나오고, 거기서 선택지 · 체험 · 아이템 사용을 합니다.
- **백사**: 일부 장소에서 확률적으로 사람으로 변장해 나타납니다. 플레이어는 **글만 보고** 이상함을 알아채야 해요. 못 알아채고 '이용'하면 스트라이크 1개, **3개면 배드엔딩**.
- 엔딩 4개: 배드 / 노멀 / 해피 / 히든 (조건은 00_전체지도.md)

👉 그래서 쓰는 단위는 "장면 하나"가 아니라 **"장소 하나"** 입니다.
장소 폴더 하나 = 그 장소에서 일어나는 모든 장면 (평소 / 백사 버전 / 체험 / 특별 장면). 아이템은 장소가 아니라 **00_아이템.md** 한 곳에 모아서 써요.

## 3. 작성 약속 (이것만 지키면 Claude가 바로 게임에 넣을 수 있어요)

1. **제목(## A. 등)과 항목 이름(본문:, 선택지 문구: 등)은 지우거나 바꾸지 않기.** 콜론(:) 뒤 빈칸만 채우기.
2. **안 쓰는 칸은 비워두기** (지우지 않기). 선택지·장면이 더 필요하면 블록을 통째로 복사해서 번호만 바꾸기 (A-4, E-2 …).
3. **조건은 말로 쓰기.** 예) "강아지가 있을 때", "2일차 이후", "오후 5시 이후 도착", "망원경을 쓴 뒤". 변수 이름은 만들 필요 없어요.
4. **시간은 분으로.** 30, 60, 90.
5. **얻는 것/잃는 것 쓰는 법:** "포도알 +3", "아이템: 망원경", "알게 된 것: 스님이 밤마다 사라진다". 목록에 없는 아이템이면 "[새 아이템] 이름"이라고 쓰고, 자세한 내용은 00_아이템.md 7번(새 아이템 제안)에.
6. **📌 고정 정보는 수정 금지.** 이동 경로·숙소·백사 확률·엔딩 조건은 게임 규칙이라 바꾸면 다른 장소가 깨져요. 바꾸고 싶으면 H 칸에 제안또는 질문으로 해주세요.
7. **영천 실제 정보**(지명·역사·특산물·전설)를 쓰면 G 칸에 출처를 꼭 적기.
8. **백사 버전 본문**: 단서는 반드시 글 속에 숨기기. "백사다!", "수상하다" 같은 직접 표현 금지. 단서 문장은 🔍 칸에 따로 적기 (게임엔 안 나오고 테스트용).
9. **본문 길이**: 한 장면에 3~6문장 정도 권장. 길어져도 괜찮으나 그러면 장면을 두 개로 나눌 예정입니다

