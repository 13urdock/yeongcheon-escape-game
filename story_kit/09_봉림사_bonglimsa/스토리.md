| 항목 | 내용 |
|---|---|
| 숙소 | 아니오 |
| 운영 시간 | 05:00부터 출입 가능 |
| 여기서 갈 수 있는 곳 | 보현산(30분) · 지네 동굴(30분, 망원경으로 발견 + 강아지 + 마지막 날) |
| 백사 | 도착할 때마다 20% 확률로 등장 |
| 백사 변장·단서 방향 | 절에서 일하는 사람이 백사 |
| 강아지·고양이 만남 | 이 장소에 도착할 때 확률로 등장 (장면 글은 00_공통장면에 작성) |
| 이 장소의 역할 | 05:00부터 출입. [히든] 09:00 전 도착 + 스님 일 돕기 + 이야기 듣기 / [해피] 예불 + 스님 이야기 몰래 엿듣기. 여기서 망원경을 쓰면 지네 동굴 발견 |
| 이미 있는 체험 | 예불 드리기 60분 · 스님 일 돕기 90분 |

이미 자리만 잡힌 장면 (본문이 비어 있음 — 아래 칸에 채우면 여기에 들어감):
- bonglimsa_arrival — 봉림사 도착 본문 (백사 미등장)
- bonglimsa_early_event — 아직 해도 다 뜨지 않은 봉림사. 스님들이 아침 일을 준비하고 있다.
- bonglimsa_monk_story — 일을 마친 스님이 차를 내주며 칠석의 백사 이야기를 들려준다.
