# 00 공통 장면 — 여러 장소에서 나오는 장면

## 📌 고정 규칙 — 수정하지 마세요

| 항목 | 내용 |
|---|---|
| 강아지·고양이 | 시장에서 팔지 않음. **야외 관광지에 도착할 때 확률로** 나타나고, 데려갈지 플레이어가 고름 |
| 등장 장소 | 돌할매 · 와이너리 · 보현산 · 봉림사 · 임고서원 · 출렁다리 · 짚라인 (숙소·시청·시장·지네 동굴 제외) |
| 확률 | 20%. **2번 연속 안 나오면 3번째 도착에서 반드시 등장** (나오면 다시 0부터) |
| 강아지/고양이 중 무엇? | 등장할 때 반반 |
| 거절하면? | 다음 야외 관광지 도착 때 다시 확률 굴림 (동행이 생기면 더 안 나옴) |
| 같이 못 데려감 | 강아지 ↔ 고양이 중 하나만. **강아지가 있어야 노멀·해피 엔딩**, 고양이를 데려가면 강아지는 못 데려감 |
| 고양이의 역할 | **일부러 넣은 '오답'.** 특별한 효과 없음 — 플레이어가 "고양이가 아니었구나"를 알고 다시 도전하게 만드는 장치. 만남 글에서 정답을 직접 알려주지 말 것 |
| 배경 | 그 장소의 배경이 그대로 나옴 (그림 따로 필요 없음) |

> 한 장면이 여러 장소에서 재사용돼요. 그래서 **특정 장소 이름은 쓰지 말고** 어디서든 어울리게 써 주세요.

## 1. 강아지 만남 (dog_encounter)
본문: 길을 걷다 우연히 시선이 아래로 향했다. 누렁이 한 마리가 꼬리를 살랑거리며 내 발걸음을 따라오고 있다. 경계심이라곤 조금도 없는 맑고 초롱초롱한 눈망울이, 마치 오래전부터 나를 알고 지낸 것처럼 친근하다. 사람 손을 제법 탔는지 가만히 내 발목에 코를 비비며 애교를 부린다.

### 선택지 1-1 데려간다
- 선택지 문구: 녀석의 머리를 쓰다듬으며 함께 가자고 한다
- 누르면 나오는 결과 문구 : 강아지가 기분 좋은 듯 꼬리를 세차게 흔들며 내 발밑에 바짝 붙는다. 영천 여행에 든든하고 귀여운 동행이 생겼다.

### 선택지 1-2 두고 간다
- 선택지 문구: 아쉽지만 모른 척하고 제 갈 길을 간다
- 누르면 나오는 결과 문구: 등 뒤에서 작게 낑낑거리는 소리가 들렸지만, 짐도 많은데 혼자 다니는 게 속 편할지도 모른다. 발걸음을 재촉하자.

## 2. 고양이 만남 (cat_encounter)
본문: 근처 구조물 위에서 가벼운 바스락 소리가 났다. 고개를 들어보니 털이 복슬복슬한 삼색 고양이 한 마리가 나른하게 식빵을 굽고 있다. 나와 눈이 마주치자 사뿐하게 뛰어내려와 다리에 몸을 스윽 비빈다. 도도하면서도 묘하게 사람을 끄는 매력적인 자태에 나도 모르게 발걸음을 멈추게 된다.

### 선택지 2-1 데려간다
- 선택지 문구: 손을 내밀어 턱밑을 다정하게 긁어준다
- 누르면 나오는 결과 문구: 고양이가 기분 좋은 골골송을 부르며 내 곁을 맴돈다. 도도하지만 사랑스러운 동행이 생겼다.

### 선택지 2-2 두고 간다
- 선택지 문구: 눈인사만 짧게 나누고 지나친다
- 누르면 나오는 결과 문구: 녀석은 별로 아쉬울 것 없다는 듯 가볍게 몸을 돌려 제자리로 돌아간다. 조용한 여행을 즐기기엔 역시 혼자가 낫다.

## 3. 질문 / 메모
1. 어느 야외 관광지에서 나와도 어색하지 않게 장소 특정이 가능한 단어는 모두 배제했습니다.
2. 고양이가 오답임을 눈치채지 못하도록 강아지와 동등한 수준의 매력적이고 긍정적인 묘사 톤을 유지했습니다.
