# 00 공통 장면 — 여러 장소에서 나오는 장면

## 📌 고정 규칙 — 수정하지 마세요

| 항목 | 내용 |
|---|---|
| 강아지·고양이 | 시장에서 팔지 않음. **야외 관광지에 도착할 때 확률로** 나타나고, 데려갈지 플레이어가 고름 |
| 등장 장소 | 돌할매 · 와이너리 · 보현산 · 봉림사 · 임고서원 · 출렁다리 · 짚라인 (숙소·시청·시장·지네 동굴 제외) |
| 확률 | 20%. **2번 연속 안 나오면 3번째 도착에서 반드시 등장** (나오면 다시 0부터) |
| 강아지/고양이 중 무엇? | 등장할 때 반반 |
| 거절하면? | 다음 야외 관광지 도착 때 다시 확률 굴림 (동행이 생기면 더 안 나옴) |
| 같이 못 데려감 | 강아지 ↔ 고양이 중 하나만. **강아지가 있어야 노멀·해피 엔딩**, 고양이를 데려가면 강아지는 못 데려감 |
| 고양이의 역할 | **일부러 넣은 '오답'.** 특별한 효과 없음 — 플레이어가 "고양이가 아니었구나"를 알고 다시 도전하게 만드는 장치. 만남 글에서 정답을 직접 알려주지 말 것 |
| 배경 | 그 장소의 배경이 그대로 나옴 (그림 따로 필요 없음) |

> 한 장면이 여러 장소에서 재사용돼요. 그래서 **특정 장소 이름은 쓰지 말고** 어디서든 어울리게 써 주세요.
